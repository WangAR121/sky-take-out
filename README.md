苍穹外卖 - Sky-Takeout
 
基于 SpringBoot + MyBatis + Redis + WebSocket 的外卖后台管理系统
本项目是苍穹外卖实战改造版本，核心优化：把循环内多次DB查询，调整为一次性批量查询、内存循环组装数据，减少数据库IO压力
----------项目亮点（和原版苍穹外卖最大区别）----------
 
原版报表统计逻辑： for循环每一天 → 循环内单独查一次数据库 ，天数越多，SQL请求次数爆炸，数据库压力大。
本版本改造方案：
 
1. 一次SQL批量查出区间内全部明细/聚合数据（利用  GROUP BY DATE(order_time)  在数据库层聚合，或一次性拉取明细）
​
2. 在 Service 内存中做循环遍历、日期补零、累计计算、数据组装
​
3. 大幅减少数据库访问次数，避免高频循环查询造成慢查询、连接池耗尽，适合日期范围较大的报表导出场景
----------技术栈--------------------
 
- 后端：SpringBoot 2.7.x、MyBatis
​
- 缓存：Redis（菜品缓存、套餐缓存）
​
- 连接池：Druid
​
- 消息推送：WebSocket（订单实时提醒）
​
- 文件导出：Apache POI（模板Excel导出）
​
- 数据库：MySQL 8.0
​
- 工具：Lombok、PageHelper、JWT
----------主要功能------------------
 
- 员工管理、菜品分类、菜品管理、套餐管理
​
- 订单管理、订单状态流转、超时订单定时任务
​
- 用户小程序端：点餐、购物车、下单、支付模拟
​
- 业务数据报表导出（核心改造模块）：营业额、有效订单、订单完成率、客单价、新增用户，支持按时间区间导出连续日期报表
​
- 实时订单推送（WebSocket）
----------快速启动-------------------
 
1. 导入SQL脚本，创建数据库  sky_take_out 
​
2. 修改  application.yml 、 application-dev.yml  中的数据库、Redis连接信息
​
3. Maven依赖加载完成，启动  SkyApplication 
​
